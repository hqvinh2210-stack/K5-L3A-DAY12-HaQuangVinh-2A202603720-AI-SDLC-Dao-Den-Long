# Đảo Đèn Lồng v1.0.0

- Chơi ba đêm trên Đảo Bến, Đảo Cau và Đảo Chuông. Châm dầu để giữ đủ đèn sáng đến bình minh.
- Bảng xếp hạng cục bộ gồm 10 điểm cao nhất và có lệnh xuất JSON.
- Đổi phím điều khiển, phụ đề sự kiện, bảng màu dễ phân biệt, giảm chuyển động và chữ lớn.
- Test Contract v1.3 thêm benchmark đồ họa và soak test.

Tải và giải nén gói web, cài Node.js 20 trở lên, chạy `node src/serve.mjs` và mở [trò chơi cục bộ](http://127.0.0.1:4173/).
